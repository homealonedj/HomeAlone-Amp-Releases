# HomeAlone Amp

Muziek- en videospeler voor Windows en macOS.

## Downloaden

[Download de nieuwste versie](https://github.com/homealonedj/HomeAlone-Amp-Releases/releases/latest)

- **Windows:** download het bestand met `Windows-x64-Setup.exe` en voer de installatie uit.
- **Mac:** download de `universal-macOS12.dmg`, open deze en sleep HomeAlone Amp naar Programma’s. Geschikt voor Intel en Apple Silicon vanaf macOS 12.

Deze openbare repository bevat alleen installatiebestanden en downloadinformatie. De broncode wordt apart privé beheerd.

Oudere versies controleren updates nog op de vorige locatie. Installeer de nieuwe versie eenmalig handmatig zodra deze beschikbaar is.
